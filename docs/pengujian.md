# Dokumentasi Pengujian TaskMate

Pengujian dilakukan pada fitur utama aplikasi.

## Pengujian CRUD
- Create: Menambahkan tugas.
- Read: Menampilkan daftar tugas.
- Update: Mengubah informasi tugas.
- Delete: Menghapus tugas.

## Pengujian Navigasi
- Dashboard menuju daftar tugas.
- Daftar tugas menuju detail.
- Halaman tambah dan edit tugas.

## Pengujian API
- Mengambil data menggunakan HTTP GET.
- Memproses response JSON menjadi model Dart.

## Pengujian Validasi
- Memeriksa input formulir.
- Memeriksa pesan kesalahan.
