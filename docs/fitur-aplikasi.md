# Dokumentasi Fitur TaskMate

## Dashboard
Menampilkan ringkasan tugas mahasiswa.

## Daftar Tugas
Menampilkan tugas yang tersimpan.

## Detail Tugas
Menampilkan informasi lengkap tugas.

## Tambah Tugas
Memasukkan tugas baru melalui formulir.

## Edit Tugas
Memperbarui informasi tugas.

## Tugas Selesai
Menampilkan tugas yang telah diselesaikan.

## Profil
Menampilkan informasi pengembang.
