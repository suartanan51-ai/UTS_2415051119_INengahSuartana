## Backend/database
Supabase PostgreSQL. Buat tabel menggunakan SQL berikut di Supabase SQL Editor:

```sql
create table public.tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  description text not null default '',
  course text not null,
  due_date timestamptz not null,
  priority text not null default 'Sedang',
  is_completed boolean not null default false,
  created_at timestamptz not null default now()
);

alter table public.tasks enable row level security;

-- Untuk demo kelas tanpa autentikasi. Batasi policy sesuai kebutuhan sebelum aplikasi dipakai publik.
create policy "demo read tasks" on public.tasks for select to anon using (true);
create policy "demo insert tasks" on public.tasks for insert to anon with check (true);
create policy "demo update tasks" on public.tasks for update to anon using (true) with check (true);
create policy "demo delete tasks" on public.tasks for delete to anon using (true);
```

> Gunakan Project URL dan anon/public key dari Supabase. Jangan pernah memasukkan `service_role` key ke aplikasi Flutter atau GitHub.

## Cara menjalankan
1. Install Flutter SDK dan Android Studio.
2. Buka folder project melalui Android Studio atau VS Code.
3. Jalankan `flutter pub get`.
4. Buat project Supabase dan jalankan SQL di atas.
5. Jalankan aplikasi dengan kredensial publik:

```bash
flutter run --dart-define=SUPABASE_URL=https://PROJECT_ID.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_ANON_KEY
```

Jika belum memasukkan konfigurasi Supabase, aplikasi tetap dapat dibuka untuk melihat UI dan REST API, tetapi operasi database belum aktif.
